# Reel 0011 Visual Storyboard and Provenance Plan

All scenes are **original deterministic SVG-to-raster motion graphics**, designed locally without embedded words, logos, watermarks, or real-person likenesses. Hindi captions are composited only at render time. This quota-safe route does not claim AI-generated images.

| Scene | Time | Original visual direction | Motion and safety boundary |
|---|---:|---|---|
| 1 | 0–8s | Abstract deep-indigo field, a neutral object constellation, and a soft focus-ring moving between visual features. | Focus ring changes position; no claim that the object itself changes. |
| 2 | 8–20s | Six invented soft-edged creatures with one shared geometric feature; that feature gently brightens across examples. | Symbolizes an experimental category-learning task, not real animals or a brain scan. |
| 3 | 20–32s | Three feature cards converge into a highlighted diagnostic feature, with remaining features muted. | Shows selective attention as a model diagram. |
| 4 | 32–45s | Split pathway: “stored cue” icon and “decision route” icon reach the same response button; no text embedded. | Visualizes alternative mechanisms without presenting a causal brain diagram. |
| 5 | 45–54s | Transparent layered network flows softly between an ear-like abstract curve, geometric label token, and eye-like aperture. | Represents a theoretical framework only; no neural proof implied. |
| 6 | 54–60s | An ordinary unbranded mug silhouette rotates; feature markers appear before a neutral label-token orbit. | Encourages observation, not self-testing or diagnosis. |

## Production requirement

Each generated SVG must carry a provenance entry with deterministic source, scene ID, no-text confirmation, and render hash. Images remain outside Git; only textual provenance and manifests are committed.
