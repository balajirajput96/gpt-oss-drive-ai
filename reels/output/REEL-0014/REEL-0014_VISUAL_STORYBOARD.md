# Reel 0014 Visual Storyboard

Six original deterministic SVG-to-raster scenes will be used because image-generation quota restrictions must not be bypassed. Source artwork will contain no text, logos, watermarks, or people; Hindi captions are composited only at render time.

| Scene | Time | Visual metaphor |
|---|---:|---|
| 1 | 0–10s | One gauge splits into several transparent component dials. |
| 2 | 10–20s | A task path branches into search, memory, speed, and response icons. |
| 3 | 20–30s | Abstract factor blocks sort into distinct clusters. |
| 4 | 30–40s | Shared central network overlaps with three task-specific orbit paths. |
| 5 | 40–51s | Two complementary windows (report and performance) show different partial views. |
| 6 | 51–60s | A magnifier passes over a neutral study card, group cluster, and question mark. |
